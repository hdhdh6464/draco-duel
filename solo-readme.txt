時光器對決 Duel of the Time-Turner — 單人版
==========================================

【怎麼打開】
1. 對 DracoDuel-Solo.zip 按右鍵 →「全部解壓縮」。
   （一定要先解壓縮，直接在壓縮檔裡點兩下會打不開。）
2. 打開解壓出來的 DracoDuel 資料夾。
3. 點兩下 DracoDuel.exe 就開始玩。不用另外安裝 Java。

如果出現藍色的「Windows 已保護您的電腦」視窗：
   按「其他資訊」→「仍要執行」。
   （這是因為遊戲沒有花錢買數位簽章，不是病毒。）

想放到桌面：對 DracoDuel.exe 按右鍵 →「傳送到」→「桌面（建立捷徑）」。
請保留整個資料夾，不要只把 exe 單獨拿出來，它需要旁邊的 app 和 runtime 資料夾。

【第一次玩】
標題畫面選「新手教程」（或按 2），會一步步教你操作，教學中不會死。

【基本玩法】
- 佛地魔每次施法前時間會停止（子彈時間），你在這時排好接下來的動作，按 Enter 開始演出。
- 半透明的虛影是預演，照計畫會發生的事一定準確；時間軸上的紅色標記＝那時會被打中。
- 正式決鬥中，馬爾福被任何攻擊打中一次就會倒下。

【按鍵】
  W A S D        移動（滑鼠左鍵點地圖＝跑過去）
  空白            等待 0.3 秒
  Q / E / Z / C  翻滾 / 側閃 / 後空翻 / 幻影移形
  1 2 3 4        暴牙咒 / 繳械咒 / 昏擊咒 / 召蛇咒（2 3 4 要先讀條，再按一次才施放）
  F G R T        跳踢 / 連拳 / 迴旋踢 / 過肩摔
  5              鐵甲咒
  Enter          開始演出      Backspace  復原      Delete  清空
  H              查看所有招式說明      M  靜音      F11  全螢幕      Esc  回標題
  比賽結束後按 P 可看整場回放

Windows 10 / 11（64 位元）可直接執行。
